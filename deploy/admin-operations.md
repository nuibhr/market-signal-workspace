# หลังบ้าน Nugaom AI Pick

## เข้าใช้งาน

ล็อกอิน LINE ที่ `/account` แล้วเปิด `/admin` บัญชีต้องอยู่ใน `ADMIN_LINE_IDS` ฝั่งเซิร์ฟเวอร์ คนทั่วไปเปิดหน้าหลังบ้านไม่ได้ และ API ทุกตัวตรวจสิทธิก่อนอ่านข้อมูล ตอบ `private, no-store`

## งานประจำ

1. ภาพรวม: ดูจำนวนลูกค้า LINE ทั้งหมด รวมคนที่ยังไม่แจ้งพอร์ต รายการรอตรวจ และคำขอต่ออายุ ตัวเลขนับทั้งฐานข้อมูล ไม่ใช่แค่หน้าที่โหลดมา
2. สมาชิก: ค้นชื่อ/โบรกเกอร์/เลขพอร์ต 4 หลักท้าย กรองสิทธิหรือบัญชีรอตรวจ แสดง 12 คนต่อหน้า
3. รายละเอียด: ใช้เลขพอร์ตเต็มจากหลักฐานภายนอกเทียบกับแฮชที่ลูกค้าแจ้ง เลขเต็มไม่ได้เก็บเป็นข้อความในฐานข้อมูล การปฏิเสธเปิดให้แจ้งใหม่แต่ไม่รีเซ็ต 14 วัน
4. เครดิต: ระบุจำนวนและหมายเหตุ ตรวจรายการก่อนยืนยัน ใช้รหัสรายการเดียวกันเมื่อคำตอบขาดหาย ระบบฐานข้อมูลทำรายการนั้นครั้งเดียว
5. โค้ด: ออกเฉพาะบัญชีที่ตรวจแล้ว โค้ดผูกกับสมาชิก ใช้ครั้งเดียวภายใน 30 วัน เก็บเฉพาะแฮช หากคำตอบขาดหาย กดยืนยันรายการเดิมจะได้โค้ดเดิม โค้ดที่ยังไม่ใช้ยกเลิกได้โดยไม่เปลี่ยนสิทธิปัจจุบัน
6. ต่ออายุ: เลือกรายการรอตรวจ ระบุอ้างอิงและยืนยันรับชำระแล้วก่อนเปิดสิทธิ ระบบไม่ตรวจยอดธนาคารอัตโนมัติ ต่อจากวันสิทธิเดิมถ้ายังไม่หมดอายุ และกดซ้ำไม่เพิ่มเดือนซ้ำ
7. สัญญาณ: ดูทีละ 7 รายการ กรองตลาด/สถานะ ตรวจราคาเข้า–ออกและเหตุการณ์ อัตราชนะคำนวณจากไม้ที่เข้าแล้วปิดพร้อมราคาจริงในบันทึกล่าสุดไม่เกิน 100 ไม้ ไม่รวมแผนที่ไม่เคยเข้า
8. ประวัติ: ดูลูกค้า ผู้ดำเนินการ เวลา เครดิตหลังรายการ และอ้างอิงต่ออายุ โดยไม่มีปุ่มแก้ผลสัญญาณย้อนหลัง

## สถานะและข้อจำกัด

- หน้า `สถานะระบบ` แสดงรายการที่ข้อมูลใช้ไม่ได้/รอลองใหม่และรอบสแกนล่าสุด ไม่ถือว่าตัวทำงานออนไลน์แปลว่าทุกตลาดสแกนได้
- สมาชิก/เครดิต/โค้ดใช้ SQLite หรือ native D1 ผ่าน repository เดียวกัน Migration 0004 เพิ่มเฉพาะตาราง/คอลัมน์/index ไม่ลบข้อมูลเดิม
- `admin_credit_grants.applied=1` ใน snapshot เป็นรายการที่บันทึกแล้ว trigger ไม่เติมเครดิตซ้ำเมื่อย้ายข้อมูล ต้องรวมตารางนี้ในการย้ายด้วย
- สำเนาที่เตรียมไว้ก่อน migration 0004 เก็บไว้เป็นหลักฐานเดิม ต้องสร้าง snapshot/manifest ใหม่สำหรับการย้ายจริง
- หลังบ้านในเครื่องใช้งานกับข้อมูลในเครื่องได้ การเปิดรับลูกค้าภายนอกยังต้องเว็บ HTTPS ถาวร LINE callback ที่ตรง origin ฐานข้อมูลและงานสแกนบนคลาวด์
- ตั้ง `BACKUP_RECOVERY_CONFIRMED=true` เฉพาะเมื่อจัดสำรองนอกเครื่องและยืนยันกู้คืนบนระบบที่ deploy แล้ว ค่านี้เป็นการยืนยันของผู้ดูแล ไม่ใช่ผลตรวจอัตโนมัติ
- `.env.local`, session, เลขพอร์ตเต็ม, snapshot และ SQL ลูกค้าไม่อยู่ใน Git
