# ผลงานสัญญาณและมุมโฟกัส — 2 ตุลาคม 2026

## ผลงานชุดเดียวกัน

- หน้าลูกค้าใช้ 100 ไม้ที่ปิดล่าสุดจาก `auto_pick_signals` แทนสรุปจำลองย้อนหลัง 3 เดือนที่คำนวณแยกชุด
- เลือกตาม `exited_at DESC, id DESC` แยกตลาด นับเฉพาะ TARGET / STOP / EXIT ที่มีราคาเข้า–ออกเป็นบวกและเวลาเข้า–ออกถูกต้อง
- Win / loss ตัดสินจากส่วนต่างราคาโดยคำนึงถึง LONG / SHORT ไม่ตัดสินจากชื่อสถานะ EXIT อาจเป็นกำไรหรือขาดทุนได้
- WAITING / OPEN / EXPIRED / REVIEW / AMBIGUOUS ไม่เข้าตัวหารอัตราชนะ ไม้เสมออยู่ในตัวหารแต่ไม่นับเป็นชนะ
- ค่าเฉลี่ยผลตอบแทนเป็นค่าเฉลี่ยเปอร์เซ็นต์ต่อไม้ น้ำหนักเท่ากัน ไม่ใช่ผลตอบแทนของพอร์ต ค่า R เฉลี่ยเฉพาะไม้ที่มีระยะ Stop ใช้ได้
- หากมีข้อมูลน้อยกว่า 100 แสดงจำนวนจริง ไม่มีการเติมไม้จำลองเพื่อให้ครบ
- Summary, แถบผล 100 ไม้, ข้อความแชร์ และประวัติที่แสดงเริ่มต้นใช้ snapshot เดียวจาก `/api/auto-pick/results?scope=closed`
- ประวัติทั้งหมดและตัวกรองสถานะยังเปิดดูได้ ครั้งละ 7 รายการ ไม่มีการลบประวัติเก่าเมื่อเกิน 100 ไม้
- `/api/signal-backtest` เป็น compatibility URL สำหรับสรุปชุดเดียวกัน สิทธิสมาชิกและ rate limit ยังใช้ตามเดิม
- ตัวสแกนไม่เรียกงานจำลอง 3 เดือนอัตโนมัติอีกแล้ว ลดการแย่งโควตาราคา งานวิจัย replay และ archive เดิมยังเก็บไว้สำหรับพัฒนาในเครื่อง

ตรวจข้อมูล ณ รอบแก้ไข: หุ้นไทยปิด 2 ไม้ ชนะ 0 แพ้ 2, IRPC 2.96 → 2.92 (-1.35%) และ KCE 76.50 → 76.00 (-0.65%) เฉลี่ย -1.00% ต่อไม้ ก่อนค่าธรรมเนียมและสลิปเพจ ทั้งสองมีเหตุการณ์ ENTRY และ STOP / EXIT เชื่อมกับรายการเดิม

## มุมโฟกัส

- แทนกระดานราคาหลายร้อยแถวด้วยการ์ดสินทรัพย์ที่เลือก แนวโน้ม ระยะถึงแนวรับ–แนวต้าน และ 6 รายการต่อหน้า
- ระดับราคาอ้างอิงจาก analysis เดิม ไม่สร้างสัญญาณเข้าใหม่จากตัวชี้ตำแหน่ง
- ค้นหา เปลี่ยนหน้า ปักหมุด แยกรายการโปรดตามตลาด เปิดกราฟ และเปิดสแกนเชิงลึกได้
- โหลด Settrade / TFEX quote เฉพาะรายการที่เห็น รีเฟรช 60 วินาที ไม่ยิงราคาทั้งตลาดพร้อมกัน
- ยกเลิกคำขอเก่าเมื่อเปลี่ยนหน้า / ตัวกรอง และไม่แสดง cached quote ที่เรียกใหม่ล้มเหลวเป็นราคาพร้อมใช้
- Yahoo แสดงราคาจากแท่งปิดที่มีข้อมูลจริง พร้อมชื่อแหล่งและเวลา โดยยังไม่ใช้ยืนยัน AutoPick
- มือถือเรียงคอลัมน์เดียว ประวัติผลสัญญาณเป็นการ์ดราคาเข้า–ออก ไม่มีตารางบังคับให้เลื่อนซ้ายขวา

## Parallax

- อ้างอิงรูปแบบจาก https://namethatui.com/web/parallax
- ฉากหลังสองชั้นเลื่อนต่างอัตรากับเนื้อหา ใช้ CSS scroll timeline เมื่อรองรับ และ passive requestAnimationFrame fallback เมื่อไม่รองรับ
- ไม่มีการเปลี่ยน wheel หรือความเร็วการเลื่อนหลัก ไม่ transform บรรพบุรุษของเมนู fixed / กราฟ / แบบฟอร์ม
- `prefers-reduced-motion` หยุด parallax และใช้การเลื่อนเข้าหาหมวดแบบทันที

## การตรวจ

- Node tests: 30 ผ่าน 0 ไม่ผ่าน รวม 103 ไม้ตัวอย่างเพื่อยืนยันหน้าต่าง 100, ไม้ EXIT ที่ขาดทุน, การแยกตลาด และไม่ลบประวัติเก่า
- Production build ผ่านใน `.next-review` แยกจาก dev server
- เบราว์เซอร์: เปลี่ยนหน้า ค้นหา ปักหมุด/คืนรายการเดิม ดูเหตุการณ์ IRPC สลับประวัติทั้งหมด (7 รายการ) / 100 ไม้ (2 รายการ)
- ขนาด 390 × 844, 837 × 766 และ 1280 × 900: ไม่มี horizontal overflow ของหน้า ตรวจ fixed menu และ grid มือถือ
- ชั้น parallax จาก transform 0 เปลี่ยนเป็นประมาณ -173 / -346 px หลังเลื่อน; เมื่อจำลอง reduced motion ทั้ง animation และ transform เป็น none
- ตัว worker ในเครื่องรีสตาร์ตหลังตรวจไม่มีรอบ RUNNING และ heartbeat กลับเป็น running
- ไม่แก้ `.env.local` ไม่ส่งคำสั่งซื้อขาย
