# FRED ใน Nugaom · 28 กันยายน 2026

หน้า **วันข่าวเศรษฐกิจ** อ่านข้อมูลจริงจาก FRED ผ่าน `/api/macro` โดยเซิร์ฟเวอร์ใช้ `FRED_API_KEY` ใน `.env.local`; คีย์ไม่ถูกส่งให้เบราว์เซอร์. ตอนนี้แสดงวันประกาศใน 45 วันข้างหน้าสำหรับ CPI, รายงานการจ้างงาน, GDP, Personal Income and Outlays และ PPI ของสหรัฐฯ พร้อมตัวเลขที่เผยแพร่แล้วล่าสุด 4 ชุด: CPI เทียบปีก่อน, อัตราว่างงาน, ผลตอบแทนพันธบัตร 10 ปี และอัตรา Effective Federal Funds. ทุกการ์ดมีวันที่ข้อมูลและลิงก์ต้นทาง.

FRED เป็นแหล่ง **ข้อมูลเศรษฐกิจและวันประกาศ** ไม่ใช่บริการพาดหัวข่าวหุ้น. ฟีดวันที่นี้ไม่ให้ชั่วโมงประกาศ, ประเทศไทย, ค่า forecast, หรือระดับผลกระทบ จึงไม่สร้างตัวเลขเหล่านั้นขึ้นเอง. ข่าวหุ้นไทย/สหรัฐฯ ยังคงอ่านจาก MarketDX ในหน้า “ข่าวไทยและสหรัฐฯ”. วันที่บนรายการ FRED เป็นวันที่ตามปฏิทินสหรัฐฯ ไม่ใช่เวลาที่แปลงเป็นกรุงเทพฯ. ค่าที่แสดงอาจถูกปรับย้อนหลัง.

API route เก็บผลสำเร็จในหน่วยความจำ 30 นาทีเพื่อลดคำขอซ้ำ และแสดงผลล่าสุดพร้อมป้าย “ข้อมูลเก่า” ได้ไม่เกิน 24 ชั่วโมงหาก FRED ขัดข้อง. แคชนี้เป็นราย process; หากรันหลายเซิร์ฟเวอร์ควรย้ายไปแคชร่วม. API ตอบสถานะ unavailable เมื่อไม่มีข้อมูลจริงและไม่สร้างข้อมูลตัวอย่าง.

**ก่อนเปิด production:** ตรวจ [ข้อกำหนด FRED API](https://fred.stlouisfed.org/docs/api/terms_of_use.html), สิทธิของ series ที่แสดง, และวิธีใช้คีย์กับแอปสมาชิก; ใส่ข้อความที่ FRED กำหนดและลิงก์ข้อกำหนดในหน้าแอป (เพิ่มแล้ว), และเพิ่มข้อความยอมรับ FRED API Terms ในข้อกำหนดการใช้แอป. เอกสาร FRED API Keys ระบุว่าผู้ใช้แอปแต่ละรายควรใช้คีย์ของตนเอง จึงต้องตรวจว่าการใช้คีย์เซิร์ฟเวอร์หนึ่งชุดกับบริการสมาชิกสอดคล้องกับเงื่อนไขหรือได้รับอนุญาตก่อน. Route ใน production ปิดไว้จนกว่าจะตั้ง `FRED_PUBLIC_DISPLAY_RIGHTS_CONFIRMED=true` หลังตรวจเงื่อนไขเหล่านี้.

เอกสาร FRED: [วันประกาศแต่ละ release](https://fred.stlouisfed.org/docs/api/fred/release_dates.html), [ค่าราย series](https://fred.stlouisfed.org/docs/api/fred/series_observations.html), [ภาพรวม API](https://fred.stlouisfed.org/docs/api/fred/).
