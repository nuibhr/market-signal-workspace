# Nugaom AI Pick · ตรวจความพร้อม Phase 1 (27 กันยายน 2026)

## ขอบเขตที่ตัดสินใจแล้ว

- แจ้งเตือน **ในเว็บเท่านั้น**: toast ระหว่างเปิดเว็บ + event history เมื่อกลับมาเปิดเว็บ ไม่ต้องใช้ LINE OA, ข้อความ หรือ browser push
- ตลาดเป้าหมาย: หุ้นไทยเช้า, TFEX, Forex 19 สินค้า และหุ้นสหรัฐฯ เฉพาะ Nasdaq-100 ตอนกลางคืน
- เครื่องมือเนื้อหาที่ควรเติมให้ครบ: ปฏิทินเศรษฐกิจและปฏิทิน XD/ปันผลหุ้นไทย
- คำว่า “พร้อมสแกน/แจ้งเตือน” ให้ใช้เฉพาะตลาดที่มีแท่งปิดจริง เวลาจากต้นทาง สิทธิข้อมูล และการติดตาม TP/SL ที่ตรวจย้อนกลับได้

## วิธีปล่อย AutoPick อีก 3 ตลาด

1. **TFEX:** เริ่มจาก S50, Gold Online, Silver Online ทีละสินค้าเมื่อได้ OHLC ของ *สัญญาเดียวกับที่จะส่งสัญญาณ* พร้อม timestamp และสิทธิข้อมูล. เลือกสัญญา active จากข้อมูลต้นทางทุกวัน ไม่ยึดชื่อ `U26` ถาวร. คำนวณราคาเป็น tick, ความเสี่ยงเป็นบาทตาม multiplier, ตรวจ margin และช่วงพัก/กลางคืนก่อน ENTRY/TP/SL. อย่าเอาราคาทอง spot หรือดัชนี SET50 มาใช้ปิดผลฟิวเจอร์ส.
2. **Forex:** เลือกผู้ให้บริการที่คืน bid/ask และ OHLC ตามคู่ที่ใช้งานจริง (รวม XAU/USD, XAG/USD หากอยู่ในสิทธิ). จุดเข้า Long เทียบ ask, ออกเทียบ bid; Short กลับด้าน. เก็บ spread และเวลาต้นทาง, ตรวจตลาดปิดสุดสัปดาห์/วันหยุดและค่าเงินบัญชี. Twelve Data composite เป็นตัวสำรวจราคาได้ แต่ไม่ใช้แทนราคา fill ของโบรกเกอร์.
3. **Nasdaq-100:** ยืนยัน constituent snapshot พร้อมวันที่มีผล, เลือกผู้ให้บริการ intraday ที่คีย์เข้าถึงได้, normalize split/dividend และ session ตลาดนิวยอร์ก (รวม DST). หลังนั้นค่อยสแกน 15m/1h และติดตามปิดผล; FMP 1D EOD ใช้สำรวจกราฟรายวันได้ แต่ยังไม่พอสำหรับสัญญาณเข้ากลางคืน.

ทุกตลาดใช้ event schema เดียวกันได้ (`PICK_READY`, `ENTRY`, `TARGET`, `STOP`, `REVIEW`) แต่ต้องมี calendar, tick/size, cost model และ source freshness ของตัวเอง. หากฟีดขาดช่วง ให้หยุดแจ้งเข้าใหม่และแสดง `DATA_GAP` ไม่เติมแท่งสมมติ.

## ลำดับลงมือเพื่อลดการแก้ซ้ำ

1. **แกนกลาง:** ฐานข้อมูลถาวร + worker ถาวร + สิทธิข้อมูล + LINE Login/ทดลอง/ต่ออายุครบวงจร; ทำ web inbox ตามสมาชิกและยืนยัน Thai AutoPick ในวันทำการ.
2. **เครื่องมือ Phase 1:** ฟีดปฏิทินเศรษฐกิจและ XD ที่มีสิทธิ, แสดงเวลาต้นทาง/ICTและสถานะข้อมูล; ผูกข่าว/เหตุการณ์กับสินทรัพย์และกฎงดสัญญาณรอบข่าวสำคัญเมื่อพิสูจน์ได้.
3. **ตลาดขยาย:** ทำ adapter และ ledger แยกตลาด เริ่ม pilot ทีละตลาดเมื่อผ่านเกณฑ์ด้านบน. สิทธิการดูกราฟไม่เท่ากับสิทธิปล่อย AutoPick.
4. **หลังเปิด:** payment gateway, ชุมชน, social, คอร์ส, chart indicator ใหม่ และเสียงพูด เป็นงานหลังความถูกต้องของข้อมูล/สัญญาณ.

## เกณฑ์จบ Phase 1

- ผู้ใช้ใหม่ล็อกอิน LINE → แจ้งพอร์ต → ได้ 14 วัน → หมดอายุ → จ่าย/รับโค้ดแอดมิน → ต่ออายุได้ และสิทธิเก่าถูกปิดตามจริง
- หุ้นไทยอย่างน้อยชุดนำร่องมี OHLC สดตาม session, แผนมี Entry/TP/SL ที่ตรวจที่มาได้, worker ไม่สร้าง event ซ้ำหลัง restart, ปิดผล/ส่งตรวจกรณีกำกวมได้
- สมาชิกเห็น toast ขณะเปิดเว็บและย้อนอ่านเหตุการณ์เดิมเมื่อกลับมา; ไม่มีคำโฆษณาว่าจะเด้งขณะปิดเว็บ
- ข่าว, ปฏิทินเศรษฐกิจ, XD ระบุแหล่ง/เวลา/ความสด; ฟีดล้มเหลวต้องบอกว่าไม่มีข้อมูล ไม่แสดงตัวเลขสมมติ
- ตัวเลข Win rate ใช้เฉพาะ signal event จริงที่ปิดผลตามกฎ; หน้าตัวอย่างไม่ปนกับสถิติสมาชิก

**ข้อสรุป:** เครื่องมือ Phase 1 ที่ผู้ใช้เสนอเพียงพอแล้วในแง่ฟีเจอร์. คอขวดที่ยังต้องแก้คือฟีดข้อมูลพร้อมสิทธิ, ความทนทานของ worker/ฐานข้อมูล, และการพิสูจน์ AutoPick ในตลาดจริง. ไม่ควรเพิ่มเมนูใหม่ก่อนสามเรื่องนี้ผ่าน.
