# แนวรับ/แนวต้านบนกราฟ และเป้าหมาย 2R

สูตรเดิมเลือก Swing ที่ใกล้ราคาที่สุดจาก 90 แท่ง และ fallback เป็น High/Low 20 แท่ง จึงชิดราคาหรืออยู่ผิดด้านเมื่อราคาทะลุกรอบแล้ว

เปลี่ยนเป็น Traditional Pivot และกรอบ Auto ตาม TradingView:

- กราฟถึง 15 นาที: OHLC ของวันก่อนหน้าที่ปิดแล้ว
- กราฟ 1H/4H: OHLC ของสัปดาห์ก่อนหน้าที่ปิดแล้ว
- กราฟ D1: OHLC ของเดือนก่อนหน้าที่ปิดแล้ว

ข้อมูลกรอบสัปดาห์/เดือนรวมจาก D1 ของสินทรัพย์เดียวกัน ไม่รวมช่วงที่กำลังเปิด หากข้อมูล D1 ไม่พอหรือ High = Low ไม่สร้างระดับสมมติแทน

P = (H + L + C) / 3
R1 = 2P − L; S1 = 2P − H
R2 = P + H − L; S2 = P − H + L
R3 = H + 2(P − L); S3 = L − 2(H − P)

แสดงเส้น P/S1/S2/S3/R1/R2/R3 ตามค่าคำนวณ ระดับที่ใกล้ราคาที่สุดในฝั่งนั้นคือแนวรับ/แนวต้านที่สรุปด้านข้าง หากราคาเกินทุกระดับจะแสดง — ไม่ดึงระดับผิดฝั่งมาทดแทน

เป้าหมายแผนฝั่ง Long คำนวณแยก:

- Entry อ้างอิงราคาที่นำมาวิเคราะห์ ไม่ใช่จุดเข้าที่ได้รับการยืนยัน
- Stop = min(Pivot support − 0.25 ATR14, Entry − ATR14)
- Risk = Entry − Stop
- Target = Entry + 2 × Risk

Stop และ Target แสดงต่างสีจาก Pivot หากแนวต้านถัดไปอยู่ก่อน Target ให้ WAIT_RESISTANCE ไม่ขยับแนวต้าน หากไม่มีแนวต้านเหนือราคาในชุด Pivot ให้ UNCONFIRMED_ROOM ไม่อ้างว่าปลอดแนวต้านทุกชนิด

แผนโครงสร้าง 3 กรอบเวลาในแถบวิเคราะห์เพิ่มขั้นต่ำ R:R เป็น 2.00 หลังปรับ tick หุ้นไทยด้วย ไม่ขยับโซนจริงเพื่อบังคับให้ผ่าน และไม่แก้ snapshot สัญญาณที่บันทึกแล้ว

สูตร Pivot เป็นระดับอ้างอิงตามกติกา ไม่ใช่หลักฐานว่ามีคำสั่งซื้อขายหรือแนวต้านจริงทั้งหมด ณ ราคานั้น
