# กราฟและแผนสัญญาณ: สิ่งที่ใช้ได้และลำดับงานถัดไป

อัปเดต 27 กันยายน 2026

## ใช้ได้ใน workspace ตอนนี้

- เมนูซ้าย “สแกน · Multi-TF · Volume” เป็นทางเข้าเดียว มี 3 แท็บในหน้าต่างวิเคราะห์เดียวกัน
- เมนู “แผนสัญญาณ” เลื่อนไปการ์ดแผนเทคนิคก่อน แล้วตามด้วยฟอร์มแผนส่วนตัว เลือกฝั่ง, Entry, Stop, Target, เงินทุน และความเสี่ยงต่อแผน คำนวณงบขาดทุนและ Reward:Risk; สำหรับตลาดเงินสดคำนวณจำนวนหน่วยสูงสุดโดยจำกัดทั้งงบเสี่ยงและทุนที่มี แล้วบันทึก/ลบในเบราว์เซอร์
- หุ้นไทย/DR ที่มีแท่งปิดครบ D1, 4H และ 1H ใช้แผนเทคนิคกติกาเดียวกัน: D1 ประเมิน Bias, 4H รวมโซนราคา และ 1H ตรวจจังหวะ เป้า TP1 เป็นขอบโซนต้าน/รับถัดไปจริง ค่า R:R ใช้คัดแผนเท่านั้น หากระยะทำกำไรน้อยกว่า 1 ATR หรือ R:R ต่ำกว่า 1.8 ระบบแสดง WAIT และไม่เติมระดับในฟอร์มอัตโนมัติ
- ฟอร์มแผนส่วนตัวรับ Entry/Stop/Target จากแผนเทคนิคเมื่อผ่านเกณฑ์ทุกข้อเท่านั้น ส่วนผู้ใช้ยังกรอกแผนร่างเองได้ ระบบเตือนถ้า R:R ต่ำกว่า 1.8 หรือ Target เลยโซนราคาที่รู้จัก
- กราฟเปลี่ยน Candles/Line และเปิดปิด EMA20, EMA50, SMA20, Bollinger Bands, Donchian20, VWAP สะสมเฉพาะช่วงแท่งที่โหลด, Volume และแนวรับ/ต้านได้ อินดิเคเตอร์คำนวณจากแท่งจริงเมื่อมีฟีด ไม่ใช้แท่ง DEMO เพื่อสร้างการวิเคราะห์
- หุ้นสหรัฐฯ ในรายการใช้ FMP EOD ที่ `/api/us-bars` สำหรับกราฟ 1D: ตัดแท่งวันปัจจุบันของ New York ออก, ตรวจ OHLCV, แสดงแหล่งและวันที่แท่งล่าสุด, แล้วคำนวณอินดิเคเตอร์ชุดเดียวกันจากแท่งปิดจริง ตัวอย่าง NVDA ในเครื่องได้ 275 แท่งถึง 25 ก.ย. 2026; ราคาปัจจุบันในแถบราคาเป็น FMP quote snapshot แยกจากแท่งกราฟ
- RSI14, MACD, ATR14, Stochastic, OBV, Relative Volume และ Standard/Camarilla/Woodie Pivot อ่านตัวเลขได้ใน Toolbox จากแท่งจริงที่ปิดแล้ว; ยังไม่เป็น pane แยกบนกราฟ

## ขอบเขตที่ยังต้องทำก่อนเรียก “สัญญาณเทรดจริง”

แผนที่กรอกเป็นร่างของผู้ใช้ ไม่ใช่สัญญาณที่ระบบรับรอง ไม่มีการส่งคำสั่งซื้อขาย การติดตาม TP/SL อัตโนมัติ หรือผล win rate จากแผนเหล่านี้ การเก็บใน `localStorage` ยังไม่ซิงก์ข้ามเครื่อง เมื่อ LINE Login และฐานข้อมูลถาวรพร้อมจึงย้ายแผนไปเก็บตาม member ID พร้อมสิทธิและประวัติแก้ไข

สำหรับหุ้นไทย/DR ต้องกำหนด board lot และข้อจำกัดฝั่ง Short ตาม instrument และบัญชีโบรกเกอร์ก่อนใช้จำนวนหน่วย/ฝั่งลงเป็นคำแนะนำการส่งคำสั่ง ตอนนี้ปิดฝั่ง SHORT สำหรับหุ้นไทย, DR และคริปโต spot แล้ว สำหรับ TFEX/Forex ยังไม่แสดงจำนวนสัญญา เพราะต้องใช้ contract size, tick value, margin, อัตราแปลงสกุลเงิน และ spread ของผู้ให้บริการนั้น ๆ

## ลำดับไม่ให้แก้ซ้ำ

1. ยืนยันสิทธิแสดง OHLCV และความครอบคลุม symbol/timeframe ในแต่ละตลาด; หุ้นสหรัฐฯ ต่อ FMP 1D ในเครื่องแล้ว ส่วน Forex ยังมีเพียง FMP quote snapshot จึงยังไม่เปิดอินดิเคเตอร์จาก quote; FMP Forex interval ตอบ 402 สำหรับแพ็กเกจที่ตั้งไว้
2. นิยามแผนระบบขั้น 02 แล้วด้วย instrument ID, เวลาแท่งอ้างอิง, entry zone, trigger, SL, TP1/TP2, score, เหตุผล, blockers และ rule version; งานถัดไปคือ persist แบบมี exchange/timezone และ snapshot ของแผนเพื่อใช้ติดตามขั้น 03
3. เก็บแผนสมาชิกในฐานข้อมูลถาวร พร้อม LINE session, ป้องกันข้อมูลข้ามบัญชีและสำรองข้อมูล; แยกแผนผู้ใช้กับสัญญาณระบบชัดเจน
4. เพิ่มตัวประเมินผลจากแท่งปิดจริง, ค่าธรรมเนียม และสถานะกรณีแท่งเดียวแตะทั้ง Stop/Target ก่อนเปิดสถิติหรือแจ้งเตือน
5. จากนั้นเพิ่ม pane RSI/MACD, drawing tools, presets และ multi-timeframe overlays ทีละกลุ่ม โดยให้ทุกปุ่มมีข้อมูลและผลที่ตรวจเห็นได้
