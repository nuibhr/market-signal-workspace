# ตรวจความพร้อมสำหรับลูกค้า · 30 ก.ย. 2026

## ใช้งานได้ในเครื่องนี้

- กราฟหุ้นไทยและ DR อ่าน OHLC จาก Settrade; กราฟ TFEX อ่าน OHLC จาก TFEX Open API. ตรวจ PTT 15 นาทีได้ 377 แท่ง และ S50Z26 15 นาทีได้ 393 แท่ง ณ 12:06 น. กรุงเทพฯ; ทั้งคู่มีแท่งล่าสุดเริ่ม 11:45 น. การกดรีเฟรชขอข้อมูลใหม่ แต่ถ้าแท่งใหม่ยังไม่ปิด แท่งล่าสุดอาจคงเดิม
- หน้ากราฟแยกเวลาแท่ง, เวลาที่เซิร์ฟเวอร์รับข้อมูล, เวลา quote เมื่อผู้ให้บริการส่งมา และเวลาที่เว็บใช้โหลด. เวลาที่เว็บใช้โหลดเป็นเวลาระหว่างเบราว์เซอร์กับแอป **ไม่ใช่ความหน่วงของราคาตลาด**. Quote PTT และ S50Z26 ที่ตรวจครั้งนี้ไม่มีเวลา quote จากต้นทาง จึงไม่อ้างว่าหน่วง 52 ms
- ข่าวแยกหุ้นไทยและหุ้นสหรัฐฯ อย่างละ 4 รายการ; FRED คืนกำหนดประกาศ 10 รายการและตัวชี้วัด 4 รายการ. ปฏิทิน XD เปิดต้นทาง SET ได้
- AutoPick ไล่รายชื่อหุ้นไทย SET100 100 ตัว + mai 50 ตัว และ DR 141 ตัวในแอป มีสถานะรายตัว, การลองใหม่ และนับจำนวนที่ยังค้าง. กติกา v3 ใช้ยอดสวิงเป็นแนวต้านและจำกัดเป้าสูงสุด 4%. หน้าเว็บให้ป๊อปอัป/เสียงเมื่อมีเหตุการณ์ ขณะเปิดเว็บเท่านั้น; เหตุการณ์เข้า/ถึงเป้า/ตัดขาดทุนถูกจัดก่อนรายการจับตา
- รอบเช้า 30 ก.ย. ปิดบัญชีรายการครบ: หุ้นไทยวิเคราะห์ด้วยข้อมูลได้ 135/150 ตัว, ไม่มีแท่งช่วงเปิดหรือแท่งปัจจุบัน 12 ตัว, ฟีดตอบไม่พร้อม 3 ตัว; DR วิเคราะห์ด้วยข้อมูลได้ 103/141 ตัว, ไม่มีแท่งหรือไม่ยืนยันช่วงซื้อขาย 38 ตัว. ไม่มีตัวค้างรอลองใหม่ แต่จำนวนที่วิเคราะห์ได้จริงต่ำกว่ารายชื่อทั้งหมด
- แผนภาคเช้าที่บันทึกไว้หมดเวลารอเข้าทั้งหมด (หุ้นไทย 49, DR 17) และยังไม่มี `ENTRY` ที่ยืนยันด้วยแท่งปิด; จำนวนแผนจับตาไม่ใช่จำนวนจุดเข้า. ต้องติดตามหลายวันก่อนปรับสูตรหรือแสดงผลชนะ/แพ้
- หน้า “ผลลัพธ์ครบทุกสัญญาณ” อ่านฐานข้อมูล AutoPick แบบแบ่งหน้าและกรองตลาด/สถานะ; แยกจุดรอเข้าตามแผน, ราคาเข้าที่แท่งยืนยัน, ราคาออกที่แท่งปิดผล และเวลาเข้า/ออก. กดแต่ละรายการเพื่อดูเส้นทางเหตุการณ์ตั้งแต่พบแผนจนหมดเวลาหรือปิดผล พร้อมราคาอ้างอิงและเหตุผล. คิดอัตราชนะเฉพาะไม้ที่เข้าและปิดผลพร้อมราคาอ้างอิงทั้งคู่. หลังเปิด worker ในรอบค่ำมีสัญญาณ 69 รายการ: 66 รายการ `EXPIRED` และ DR อีก 3 รายการ `WAITING_FOR_ENTRY` (TSLA80, NVDA80, LLY80) ยังไม่มีไม้ยืนยันเข้า จึงแสดงอัตราชนะเป็นขีดว่าง ไม่ใช่ 0% หรือผล DEMO. ราคานี้เป็น OHLC reference ไม่ใช่ fill จากพอร์ตลูกค้า และยังไม่รวมค่าธรรมเนียม/สลิปเพจ
- ถอด YOUR SIGNAL PLAN, สมุดวางแผน/ผล DEMO ที่ซ้ำ, ป๊อปอัปจำลองสัญญาณ และกราฟ/ราคา DEMO ออกจากหน้าใช้งาน. ซ่อนหมวดคริปโตที่ยังไม่มีฟีด และซ่อนเมนูคุยกับทีม/ชุมชน DEMO ที่ยังส่งข้อความจริงไม่ได้
- TFEX เลือก S50Z26 ก่อนสัญญา SET50 อื่นที่ยังไม่หมดอายุ; กราฟและ quote ของซีรีส์ Z แสดงได้
- เว็บและ worker เป็นคนละโปรเซส. ช่วงตรวจพบว่าเว็บยังเปิด แต่ worker ไม่ได้รัน จึงเปิด `npm run autopick:worker` กลับขึ้นมา; รอบ DR ภาคค่ำเผยแพร่ 3 แผนที่รอจุดเข้า. เพิ่ม heartbeat ในฐานข้อมูลและแสดงสถานะโปรเซสแยกจากเวลารอบสแกนล่าสุด. ตรวจ API เวลา 20:50 น. กรุงเทพฯ แสดง `workerProcess.status=running`; DR ภาคค่ำลองครบ 141 ตัวแล้ว: 51 ตัวประมวลผลจบ, 65 ตัวไม่ยืนยันช่วงซื้อขาย, 25 ตัวรอแท่งใหม่/ลองซ้ำในรอบต่อไป. การเปิดโปรเซสในเครื่องนี้ยังไม่ใช่บริการถาวรหลังรีสตาร์ตหรือเครื่องหลับ

## ปรับหน้าสแกนรอบค่ำ 21:09 น.

- ราคาเข้าของ AutoPick อ้างอิงราคาปิดแท่งที่ยืนยันเงื่อนไข. การ์ดสัญญาณแยกคำว่า “แผนรอเข้า” กับ “เข้าอ้างอิง” เพื่อไม่ให้ราคาในแผนถูกอ่านเป็นราคาเข้าจริง
- หุ้นไทยที่ Settrade ปฏิเสธในรอบนี้ 3 ตัว (`LIGHT`, `PSTC`, `THCOM`, HTTP 400) ถูกพับไว้ในรายละเอียดพร้อมเหตุผล; ยังอยู่ในรายการสินทรัพย์เพื่อให้ตรวจใหม่วันถัดไป
- หุ้นสหรัฐฯ ถูกพับจากหมวดสแกนที่พร้อมใช้ แม้อยู่นอกเวลาสแกน เพราะรอบเต็มล่าสุดยังไม่ผ่านและ FMP ตอบ `PLAN_REQUIRED` 82 ตัว. TFEX และ Forex ที่ยังไม่เปิดสัญญาณอยู่ในกลุ่มพับเดียวกัน กราฟของสินทรัพย์ที่มีข้อมูลยังเข้าถึงได้จากหน้าสำรวจราคา
- DR ที่ไม่มีแท่งช่วงเปิดหลังรอครบหนึ่งชั่วโมงถูกจัดเป็น “ไม่เหมาะกับรอบนี้” แทนการลองซ้ำไม่สิ้นสุด. หลังปรับ worker รอบค่ำจัดสถานะครบ `141/141`: ประมวลผลจบ 52 ตัว, ไม่เข้าเกณฑ์ช่วงซื้อขาย/แท่งเปิด 89 ตัว, ไม่มีตัวค้างลองใหม่. รอบใหม่จะตรวจข้อมูลอีกครั้ง
- หลังบ้านสมาชิกปัจจุบันอยู่ในหน้าบัญชีและ API แอดมินตรวจสิทธิจาก LINE user ID. แนวทางระยะถัดไปคือแยกหน้าผู้ดูแลออกจากหน้าลูกค้าในแอปเดียวกัน พร้อมหน้าสถานะฟีด/worker, คิวตรวจพอร์ต, ต่ออายุ/โค้ด/เครดิต, และบันทึกการเปลี่ยนแปลง ยังไม่จำเป็นต้องแยกเซิร์ฟเวอร์หรือฐานข้อมูลอีกชุดในระยะนี้

## ยังไม่พร้อมขายเป็นระบบแจ้งสัญญาณครบทุกตลาด

1. บัญชี LINE ในเครื่องนี้ยังไม่ตั้งค่า (`/api/account` แสดง `configured:false`) จึงยังตรวจสมัคร, แจ้งพอร์ต, ทดลอง 14 วัน, สิทธิสมาชิก, จ่ายรายเดือน และเสียงสำหรับสมาชิกจริงแบบครบวงจรไม่ได้
2. กติกา AutoPick v3 ยังไม่พิสูจน์ผลย้อนหลังหลังค่าธรรมเนียมและส่วนต่างราคา. การเพิ่มรายการจับตาไม่เท่ากับการยืนยันจุดเข้า และไม่ใช่คำสั่งซื้อ
3. สัญญาณ TFEX และ Forex ยังปิด. TFEX ต้องยืนยันสัญญานำ สภาพคล่อง เวลาซื้อขาย และความเสี่ยง; Forex ยังไม่มีฟีด broker bid/ask พร้อมแท่งที่ใช้ยืนยันเหตุการณ์
4. สหรัฐฯ เป็น FMP รายวันหลังตลาดปิด ไม่ใช่สัญญาณระหว่างวัน. รอบ 29 ก.ย. พยายามครบ 101 ตัว แต่ 82 ตัวได้ HTTP 402 (`PLAN_REQUIRED`); ทวน GOOG อีกครั้งยังตอบเหมือนเดิม. จึงยังไม่พร้อมอ้างว่าสแกน Nasdaq-100 ครบด้วยสิทธิ API ปัจจุบัน แม้บางหุ้นดูกราฟได้
5. ปฏิทินเศรษฐกิจ FRED ที่มีแสดงวันประกาศ ยังไม่ครบเวลาออกข่าว, forecast และ actual สำหรับข่าวทุกประเภท. ปฏิทิน XD ยังเป็นลิงก์ไป SET; ยังไม่คัดกรองหรือแจ้งเตือน XD ในแอป
6. ประวัติผลสัญญาณผูกกับ AutoPick แล้ว แต่ยังไม่มีไม้เข้า/ปิดผล จึงยังไม่ใช่ backtest 3 ปี และยังไม่มีหลักฐานผลตอบแทนหลังต้นทุน. ช่องทางคุยกับทีม/ชุมชนยังไม่เชื่อมระบบส่งข้อความ จึงซ่อนจากเมนูลูกค้า

## ถ้าต้องการตัวเลขความหน่วงราคาจริง

ต้องมีฟีดตลาดที่ให้เวลาต้นทางต่อ quote/tick, สิทธิแสดงข้อมูลแก่สมาชิก, ตัวรับข้อมูลต่อเนื่อง เช่น WebSocket, เวลาเซิร์ฟเวอร์ที่ซิงก์, และตัววัด `เวลาที่แอปรับ - เวลาต้นทาง` พร้อมสถานะขาดช่วงและการกู้คืน. วัดเวลา HTTP ของปุ่มรีเฟรชอย่างเดียวตอบเรื่องความสดของราคาไม่ได้. กราฟ Lightweight Charts แสดงข้อมูลที่แอปส่งให้; ไลบรารีกราฟไม่ได้จัดหาฟีดราคาให้เอง.

ลำดับก่อนเปิดสมาชิกจริง: LINE และสิทธิสมาชิก → ยืนยันสิทธิข้อมูล/เวลา quote → ติดตามผลสัญญาณจริงและค่าใช้จ่าย → เปิด TFEX/Forex ตามฟีดที่พิสูจน์แล้ว → เติมปฏิทิน/ XD ในแอป.
