# พอร์ตจำลองของโค้ช

## เส้นทาง

- `/admin` → **พอร์ตโค้ช**: ค้นหาสมาชิก LINE, สร้างพอร์ต, เปิด/ซ่อนจากลูกค้า, พัก/เปิดใช้งาน
- `/coach`: เจ้าของพอร์ตบันทึกการเข้าและปิดไม้ของตนเอง
- `/coaches`: ลูกค้าดูเฉพาะพอร์ตที่แอดมินเปิดเผย
- `/coaches/[id]`: ลิงก์หน้าผลงานรายโค้ช มีป้ายพอร์ตจำลองตลอดหน้า

ชื่อและรูปโค้ชมาจากสมาชิก LINE ที่แอดมินเลือก ไม่สร้างสมาชิกปลอม ทุนเริ่มต้นกำหนดครั้งเดียว หนึ่งสมาชิกมีหนึ่งพอร์ตต่อสกุลเงิน พอร์ตใหม่ไม่เผยแพร่ ไม่ต้องซื้อสิทธิสมาชิกเพื่อจัดการพอร์ตที่แอดมินมอบหมาย การเป็นโค้ชไม่ให้สิทธิหลังบ้านลูกค้าหรือพอร์ตคนอื่น

## ขอบเขตและราคา

เป็น **paper trade ที่บันทึกด้วยมือ** รองรับซื้อและปิดเต็มไม้ หุ้นไทย/DR (THB), หุ้นสหรัฐฯ/ETF (USD) จำนวนหุ้น/หน่วยเป็นจำนวนเต็ม ไม่มีคำสั่งซื้อขายจริง ไม่มีการอ้างว่าเป็น broker fill ไม่ได้เชื่อมพอร์ต MT5 หรือคัดลอก AutoPick อัตโนมัติ

ราคาเป็นราคาอ้างอิงที่โค้ช/ผู้ดูแลระบุ มีเหตุผลเข้า/ออก ค่าธรรมเนียม และเวลาเซิร์ฟเวอร์ ไม่มีช่องย้อนหลังวันเวลา ไม่มีการแก้ราคา ลบแพ้ รีเซ็ตทุน หรือเติมเงินระหว่างทาง หากระบุราคาผิดให้พักพอร์ตและตรวจประวัติกับผู้ดูแล ไม่ใช่ลบรายการเพื่อแต่งสถิติ

## เงินและผลลัพธ์

- เงินพร้อมใช้ = ทุนเริ่มต้น − ต้นทุนเปิดไม้ทั้งหมด + เงินรับจากไม้ที่ปิด
- ต้นทุนเปิด = ราคาเข้า × จำนวน + ค่าธรรมเนียมเข้า
- เงินรับปิด = ราคาออก × จำนวน − ค่าธรรมเนียมออก
- กำไร/ขาดทุนสุทธิ = เงินรับปิด − ต้นทุนเปิด
- ชนะ / แพ้ / เสมอ: ผลสุทธิ > 0 / < 0 / = 0
- Win rate = จำนวนชนะ ÷ ไม้ปิดทั้งหมด รวมเสมอ ไม่รวมไม้ยังถือ
- ผลตอบแทน = ผลสุทธิของไม้ปิดทั้งหมด ÷ ทุนเริ่มต้น
- มูลค่าตามต้นทุน = เงินพร้อมใช้ + ต้นทุนไม้ที่ยังถือ **ไม่ใช่มูลค่าตลาดหรือ equity สด**

THB และ USD แยกกัน ไม่รวมข้ามสกุลเงิน ราคาละเอียดได้ 6 ตำแหน่ง เงินและค่าธรรมเนียมเป็นหน่วยย่อย (สตางค์/เซนต์) ปัดแต่ละรายการด้วย integer arithmetic สถิติรวมตั้งแต่เริ่มพอร์ต ประวัติกรองยังถือ/ปิดแล้วได้ หน้าละ 7 ไม้

## การเก็บข้อมูลและสิทธิ

D1 migration `0007_coach_portfolios.sql` และ SQLite version 7 เพิ่ม coach_portfolios, coach_trades, coach_operations โดยไม่แก้ ledger สัญญาณเดิม ใช้ transactional batch + optimistic version + operation ID/payload hash ป้องกันยอดเงินชนกัน การกดย้ำ และการใช้ operation ID เดิมกับรายการใหม่ ความเปลี่ยนแปลงทุกครั้งเก็บ actor และเวลาที่ coach_operations ไม่มี API ล้างประวัติ

POST ตรวจ LINE session, เจ้าของ/แอดมิน, Origin, JSON size และ rate limit โค้ชเผยแพร่พอร์ตเองไม่ได้ หน้าลูกค้าไม่ส่ง LINE user ID, session, เลขบัญชี หรือ owner ID พอร์ตที่ซ่อนจะเป็น 404 ใน public API สถิติอ่านใน batch เดียวให้ตรงกับเงินพร้อมใช้

ต้อง apply migration ก่อน deploy เว็บและก่อน migration ข้อมูล SQLite → D1 ตารางใหม่รวมอยู่ใน manifest/backup เช่นเดียวกับข้อมูลเดิม ไม่ใส่ `.env.local` ใน Git หรือ bundle
