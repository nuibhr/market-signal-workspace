# Acceptance review — 2 October 2026

## Completed

- 27 automated tests passed across market data, AutoPick, customer payloads and security.
- Production Next.js build passed, including the final isolated review build.
- Customer APIs explicitly omit formula gates, raw strategy reasons and provider debug data.
- Signal results default to seven rows. Browser fixture review confirmed seven rows on page one and two on page two, with nine total records.
- Settled signals aggregate from stored entry/exit outcomes; pending signals do not inflate wins. The isolated browser fixture showed three wins and three losses from six settled signals.
- Historical replay is a whole-market aggregate, separate from recorded signal performance. Old first candles alone no longer certify a complete three-month period. Cache model moved to aggregate-v3.
- Mobile review at 390×844 confirmed document width 390 with no page-level horizontal overflow.
- Browser review used a temporary database and fake session, not customer records. Test cookie was removed and viewport reset afterward.
- Browser console hydration warnings were limited to browser-extension-injected __processed_* body attributes; no application exception was observed in the reviewed flow.
- Environment templates updated to match the current catalog-based Thai/DR universes.

## Remaining deployment limitations

- Cloudflare target is Workers + Cron + D1, but the current application still requires Node and SQLite. The prepared schema is not a completed deployment; asynchronous D1 repositories, scheduler/queue port and a production hostname remain necessary.
- US signals currently use daily EOD bars, not intraday execution. TFEX and Forex signal generation remain explicitly blocked pending their required feed/risk setup.
- Historical reports remain labelled partial until trading-day coverage is validated. Fixture win rates are test data only and are not market performance or proof of profitability.
- A real market entry and audible playback were not triggered in this acceptance review; automated signal lifecycle and announcement text checks passed.

## Git safety

Private environment files, SQLite data, customer records and build directories remain ignored. Only blank environment templates belong in Git. Before commit, staged files are checked against local credential values and common credential formats without printing the credentials.
